# Grok Desktop 0.2.4

侧栏日期跟真实对话走，新消息不再滚到旧问题上，外观里可以换应用图标。

- 侧栏日期和排序使用最后一次真正的对话活动。只打开会话、刷新列表或重命名，不再把日期写成今天。
- 发出的新消息滚到自己这一条。点「回到这条问题」才回到置顶的旧问题。很长的会话重新打开时，最后一页里已经有问题的，上面还能放下的对话会留下来。
- 长会话不再只读末尾约 2MB 或 500 条。
- 外观可以切换新图标和旧图标。任务栏、窗口、托盘和桌面快捷方式「Grok Desktop」立刻更换。便携包 exe 文件本身的图标仍是打包时写入的新图标。
- 回复标题显示该会话的思考强度，切换后记在这个会话上。
- 后台任务补完那一句并结束后，运行状态会停下来。正在说话时，所在目录和这条对话排到左侧最上方，说完后仍留在那里。
- 启动时检查 Grok CLI。有新版本时询问，同意后安装并自动重启应用。桌面版更新仍只提示。

Windows 仅提供便携版：`Grok-Desktop-0.2.4-Windows-Portable-x64.exe`。退出旧版本后打开新版，沿用本机已有配置和会话。

Linux / macOS 可从源码构建。
