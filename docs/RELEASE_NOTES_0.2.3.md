# Grok Desktop 0.2.3

清除目标后，后台命令的完成通知不再自动唤起模型继续执行；后台运行时，输入区也会正确显示停止按钮。

- 清除/暂停目标和停止生成会结束当前会话的 CLI 运行进程。下一次明确发送消息时自动重新连接，保留模型与思考强度选择。
- 修复清除后写回虚假暂停目标、后台轮次被误判为空闲、旧进程退出影响新连接的问题。
- 应用“清晰灰阶”：思考区为对话宽度的 92%，采用 13px 中性灰文字、1.85 行距和浅灰竖线；最终回复保留 15px 正文。支持浅色和深色主题。
- 合并此前本地 0.2.2 的目标命令隔离、跨会话浮层、真实上下文占用、Grok 4.7/Fast 费率和按模型累计用量修复。

Windows 仅提供便携版：`Grok-Desktop-0.2.3-Windows-Portable-x64.exe`。退出旧版本后打开新版，沿用本机已有配置和会话。

Linux / macOS 可从源码构建。

验证：128 项单元测试，以及语法、类型、格式、Lint、CSS、性能和 Windows Electron 界面回归检查。
