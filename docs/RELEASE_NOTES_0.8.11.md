# Grok Desktop 0.8.11

## 中文更新

本次更新重点：

### 工作模式（输入区左侧）
- **任务模式**：默认直接执行与改代码
- **计划模式**：先出方案再动手，可打开计划面板
- **目标模式**：跨轮目标，发送时自动包装，气泡显示你的原文

### 记忆管理
- 常用记忆与经验记忆：查看、新增、编辑、分类、筛选、删除
- 可控制是否参与助手上下文

### 消息操作（气泡旁三个小按钮）
- **复制**：复制该条消息全文（折叠时也是完整原文）
- **转发 / 新任务**：带最近上下文创建独立分支任务继续跑，原任务不受影响
- **记忆**：把内容收入记忆

### macOS 体验
- 菜单栏托盘图标改为透明线稿（Template），不再显示大黑底块
- 继续支持 macOS 打包与 Dock / 合盖等桌面行为

## English

### Work modes (composer)
- **Task / Normal** — execute directly
- **Plan** — plan first, then act
- **Goal** — multi-turn goals with automatic wrapping

### Memory management
- View / add / edit / filter / delete memories; control context inclusion

### Message actions
- **Copy** full message text
- **Branch / forward** into a new independent task
- **Save to memory**

### macOS
- Menu-bar tray icon is now a template (no black plate)
