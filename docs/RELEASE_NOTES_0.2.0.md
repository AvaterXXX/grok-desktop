# Grok Desktop 0.2.0

本次更新修复默认模型记忆和文件查看体验，并改进历史对话展示。

- 重启、新建会话后沿用上次保存的默认模型，刷新模型列表不会切回 Grok 4.6。
- 中文文件名和带空格的路径可点击预览；右键支持打开、定位与复制路径。
- 文件预览可切换当前内容与历史修改记录。文本最多预览前 512 KB；其他格式使用系统默认程序。
- 历史会话恢复修改文件汇总，每轮只显示一份，放在答复末尾。
- 修复思考顺序、折叠状态以及过程说明和最终答复的排版。

Windows x64 用户可选择便携版或安装版。请完全退出旧版（包括系统托盘）后启动新版。

Linux / macOS 可从源码构建。本次不附带这两个平台的安装包。
